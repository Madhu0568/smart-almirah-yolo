Smart Almirah — Illustrative API response
========================================

This is an example of the response structure only. Values, labels, confidence,
bounding boxes, colors, and inference times are produced by your model and
hardware at runtime. This is not a measured benchmark or a recorded model run.

Request:
  POST /api/detect
  Content-Type: multipart/form-data
  image = sample.jpg

Illustrative response:
{
  "detections": [
    {
      "item_id": "generated-detection-id",
      "category": "class-name-from-your-trained-model",
      "color": "estimated-color",
      "confidence": 0.91,
      "bounding_box": {
        "x": 120,
        "y": 85,
        "width": 180,
        "height": 260
      },
      "inference_time_ms": 0.0,
      "detected_at": "runtime-UTC-timestamp"
    }
  ],
  "count": 1,
  "inference_time_ms": 0.0,
  "model": "best.pt",
  "source": "upload"
}

The application stores each detection event in the detection_log table and
updates the inventory aggregate for the matching category and estimated color.

Useful follow-up requests:
  GET    /api/inventory
  GET    /api/inventory/summary
  GET    /api/detection-log
  GET    /api/stats
  DELETE /api/inventory/<item_id>
